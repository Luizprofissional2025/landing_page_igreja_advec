## 💻 Sobre o projeto

O **ADVEC** é uma landing page desenvolvida durante minha jornada de aprendizado em **Desenvolvimento Web**.

O projeto foi criado com o objetivo de praticar a construção de uma página institucional utilizando **HTML5, CSS3 e Bootstrap**, explorando componentes visuais, responsividade e organização de conteúdo.

A página reúne diferentes informações e recursos relacionados à igreja em uma única interface

---

## ✨ Funcionalidades

| Recurso               | Descrição                                               |
| --------------------- | ------------------------------------------------------- |
| 🧭 **Navegação**      | Menu para acesso às principais seções                   |
| 📱 **Responsividade** | Adaptação da interface para diferentes tamanhos de tela |
| 🎞️ **Carrossel**     | Apresentação de imagens com navegação automática        |
| 📖 **Versículos**     | Seção dedicada aos versículos do mês                    |
| 🙏 **Evangelismo**    | Área destinada ao conteúdo de evangelismo               |
| 📚 **Catálogo**       | Organização de materiais por categorias                 |
| 🗂️ **Abas**          | Separação do catálogo em diferentes categorias          |
| ✉️ **Contato**        | Formulário para contato                                 |
| 📍 **Localização**    | Exibição do endereço                                    |
| 📱 **Redes sociais**  | Área destinada às redes sociais                         |

## 🛠️ Tecnologias

* **HTML5** — estrutura e organização da página
* **CSS3** — estilização, layout e responsividade
* **Bootstrap** — componentes e sistema de grid responsivo
* **Bootstrap Icons** — ícones utilizados na interface
* **Google Fonts** — tipografia e identidade visual
* **Git** — controle de versão
* **GitHub** — gerenciamento e hospedagem do código

## 🧠 Conhecimentos praticados

Durante o desenvolvimento, foram praticados conceitos importantes de **Front-end**, como:

* 🧱 Estruturação de páginas com HTML5;
* 🎨 Estilização utilizando CSS3;
* 📐 Desenvolvimento de layouts responsivos;
* 🧩 Utilização do sistema de Grid do Bootstrap;
* 🎞️ Implementação de carrosséis;
* 🗂️ Utilização de componentes de abas;
* 📝 Estruturação de formulários;
* 🔗 Navegação entre seções;
* 📦 Organização de arquivos e assets;
* 🎯 Personalização de componentes do Bootstrap.

---

## 📱 Responsividade

O projeto utiliza recursos responsivos do **Bootstrap**, juntamente com regras próprias de CSS para adaptar determinados elementos da interface a diferentes tamanhos de tela.

A proposta é proporcionar uma experiência consistente em **computadores, tablets e dispositivos móveis**.
